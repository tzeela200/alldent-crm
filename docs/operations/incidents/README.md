# ALLDENT Incident Records

This directory contains evidence-based incident investigations, approved
repair plans, implementation results, and regression verification.

Naming convention:

INC-YYYYMMDD-NNN-short-description.md

Lifecycle:

1. Investigating
2. Root cause proven
3. Repair proposed
4. Code approved
5. Supabase approved, when applicable
6. Data correction approved, when applicable
7. Implemented
8. Acceptance verified
9. Regression verified
10. Closed

An incident is not closed merely because the UI appears to work.

Closure requires runtime evidence, persistence verification, and regression
results.

Never place secrets or unmasked personal information in incident files.
